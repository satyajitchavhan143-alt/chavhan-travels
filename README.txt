CHAVHAN TRAVELS WEBSITE — FREE STARTER

FILES
- index.html: the complete website. No build step or extra files needed.

TEST IT ON YOUR COMPUTER
1. Download and unzip chavhan_travels_website.zip.
2. Double-click index.html. It opens in your browser.
3. Try the Marathi button and submit a sample enquiry. WhatsApp will open with a pre-filled message.

PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in/create an account at https://github.com/
2. Create a new PUBLIC repository named chavhan-travels-website.
3. Upload index.html (the file itself, not the ZIP) using Add file → Upload files → Commit changes.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; branch main, folder /(root); Save.
6. Wait a few minutes. The Pages screen will show your live website URL.
7. Open the URL on your phone and test both booking forms.

NOTES
- The website is a bilingual bus/train enquiry site. It does not itself issue tickets or check live seat availability.
- Bus and train enquiry forms open WhatsApp at +91 93702 24356.
- Train ticket booking must be processed through your authorized IRCTC workflow; bus booking must use your approved provider workflow.
- Do not collect OTP, UPI PIN, CVV, passwords or unnecessary sensitive information.
- The GitHub Pages public repository means the website source code is publicly visible. Do not put private customer data in the files.
- A custom domain is optional and usually costs money; the GitHub Pages address is free.
